# Changelog

Versions follow [Semantic Versioning](https://semver.org/). A release is a plain `x.y.z` tag that
matches `package.json`; the GitHub mirror builds it and publishes it for HACS.

## Unreleased

First version.

- Four views: at a glance, list, agenda and a busy-day heatmap (a month, or a year of small months).
- Check off and reopen in one tap; quick add with PeckList's own grammar; edit title, date, time,
  priority, tags and notes; delete.
- Several people on one card, combined: a color per person with a stripe on each task, a button per
  person with their open count, and a shared task shown once.
- Compact spacing for small dashboard cells: one line per task, the add box behind a + button, and
  groups side by side when the card is wide.
- Which tasks: everything a person can see, only their own lists, or only what is assigned to them;
  by list and by tag.
- A visual editor; sorting, compact or comfortable spacing, completed tasks, a fixed height.
- Colors follow the Home Assistant theme, or use PeckList's Forest palette.
- A wall tablet layout: big touch targets, adding through Assist voice.
