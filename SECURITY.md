# Security

Please report a security problem privately, not in a public issue:

- on GitHub, with **Report a vulnerability** under the repository's
  [Security tab](https://github.com/KillSwitchIO/pecklist-card/security), or
- on GitLab, as a [confidential issue](https://gitlab.com/killswitch10/pecklist-card/-/issues/new?issue[confidential]=true).

Say what you found, how to reproduce it, and which versions of the card, Home Assistant and PeckList
you used. You'll get an answer within a week. Fixes go out as a new release; only the latest
release gets them.

A problem in the PeckList server or app itself belongs to
[PeckList's security policy](https://gitlab.com/killswitch10/pecklist/-/blob/main/SECURITY.md).
